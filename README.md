# SQL Chinook Practice Project

## About the Project

This repository contains SQL queries developed while learning and practicing SQL using the Chinook database.

The goal is to strengthen SQL fundamentals and practice querying relational databases through practical exercises.

## Topics Covered

* Basic queries using `SELECT`, `WHERE`, and `DISTINCT`
* Sorting results with `ORDER BY`
* Combining tables with `INNER JOIN` and `LEFT JOIN`
* Aggregate functions: `COUNT()`, `SUM()`, and `AVG()`
* Grouping data with `GROUP BY`
* Filtering aggregated results with `HAVING`
* Limiting results with `LIMIT`
* String concatenation
* Window functions: `ROW_NUMBER()` and `SUM() OVER()`

## Project Structure

* `sql-chinook.sql`: SQL queries with comments explaining the purpose of each exercise.

## Database

The project uses the Chinook database, a sample relational database representing a digital music store.

## Learning Goals

* Practice writing SQL queries.
* Understand relationships between database tables.
* Summarize and analyze data using aggregate functions.
* Apply window functions to ranking and cumulative calculations.

## Status

Learning project — continuously improving SQL skills through practical exercises.
